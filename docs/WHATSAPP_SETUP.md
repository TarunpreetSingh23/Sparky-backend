# WhatsApp Cloud API Setup Guide

This guide details how to configure, run, and maintain the Meta WhatsApp Business Cloud API integration for the Sparky backend.

---

## 1. Meta Developer Portal Setup

To connect the backend to WhatsApp, you must register a Meta Developer Application.

### Step 1: Create a Meta App
1. Go to the [Meta for Developers Portal](https://developers.facebook.com/).
2. Log in and click **My Apps** > **Create App**.
3. Select **Other** > **Next**.
4. Choose **Business** as the app type > **Next**.
5. Fill in the App Name, Contact Email, and link your **Business Manager Account** (if available) > **Create App**.

### Step 2: Add WhatsApp Product
1. In your App Dashboard, scroll down to **Add products to your app**.
2. Find **WhatsApp** and click **Set up**.
3. You will be prompted to accept terms and select/create a Meta Business Account.

### Step 3: Retrieve Temporary Credentials
Under **WhatsApp** > **API Setup** on the left menu, retrieve:
- **Temporary Access Token**: Expires in 24 hours (use for dev testing).
- **Phone Number ID**: A numeric ID representing the sender phone number (e.g., `103827492719`).
- **Test Phone Number**: A mock sender number provided by Meta to send messages to up to 5 verified recipient numbers.

---

## 2. Environment Variables Configuration

Add the following environment variables to your `.env` (or server environment) to connect the credentials.

```env
# Meta WhatsApp Cloud API credentials
WHATSAPP_TOKEN=your_permanent_or_temporary_token
WHATSAPP_PHONE_NUMBER_ID=your_phone_number_id
WHATSAPP_VERIFY_TOKEN=your_arbitrary_webhook_verify_token
WHATSAPP_API_VERSION=v19.0

# Mock mode (set to true to bypass Meta API during dev/testing)
MOCK_WHATSAPP=false
```

- **`WHATSAPP_TOKEN`**: Retrieve from Developer portal (Temporary) or System User Access Token (Permanent).
- **`WHATSAPP_PHONE_NUMBER_ID`**: Found in the API Setup page.
- **`WHATSAPP_VERIFY_TOKEN`**: A custom secret string you choose (e.g., `sparky_webhook_verify_secret_2026`). You will input this into Meta's dashboard to verify your webhook.
- **`WHATSAPP_API_VERSION`**: Defaults to `v19.0`.

---

## 3. Webhook Configuration

To receive messages from Meta, configure the Webhook endpoint:

1. In your Meta App Dashboard, navigate to **WhatsApp** > **Configuration**.
2. Under **Webhook**, click **Edit**.
3. Enter:
   - **Callback URL**: `https://your-domain.in/api/whatsapp/webhook`
   - **Verify Token**: The same value as your `WHATSAPP_VERIFY_TOKEN` env variable.
4. Click **Verify and save**. Meta will make a verification `GET` request to your endpoint.
5. Once verified, scroll down to **Webhook fields** and click **Manage**.
6. Check **Subscribe** next to **`messages`** (essential to receive user texts, buttons, and replies).

## 4. Local Development & Testing

Since Meta requires a public HTTPS URL for webhooks, use a tunnel like `ngrok` or `localtunnel` during local development:

```bash
# Start your local server
npm run dev

# Expose port 3000 to HTTPS
ngrok http 3000
```
Use the HTTPS URL generated by ngrok as the Callback URL in the Meta Webhook setup.

### Development Testing Endpoint
We created a dev-only HTTP API to test responses without needing Meta setup:
- **Endpoint**: `POST /api/whatsapp/test`
- **Body**:
  ```json
  {
    "phone": "919876543210",
    "message": "Hi"
  }
  ```
- **Response**:
  ```json
  {
    "success": true,
    "reply": "👋 Welcome to Sparky Support...",
    "state": "MAIN_MENU",
    "mode": "BOT"
  }
  ```

## 5. WhatsApp Message Templates

Meta restricts sending free-form outbound text messages to users unless they have initiated a message in the past 24 hours. To start a conversation outside this window, you must use **Pre-approved Templates**.

### Configure Template Names
Create templates on [Meta Business Manager](https://business.facebook.com/) under **WhatsApp Manager** > **Message Templates**. You can configure their names in the backend via env variables:

- `TEMPLATE_BOOKING_CONFIRMATION` (default: `booking_confirm`)
- `TEMPLATE_BOOKING_REMINDER` (default: `booking_remind`)
- `TEMPLATE_BOOKING_COMPLETED` (default: `booking_complete`)
- `TEMPLATE_PAYMENT_CONFIRMATION` (default: `payment_confirm`)
- `TEMPLATE_SUPPORT_TICKET` (default: `support_ticket`)
- `TEMPLATE_OTP` (default: `otp_verify`)

## 6. Troubleshooting

- **Server returns 403 on webhook verification**: Verify that `WHATSAPP_VERIFY_TOKEN` matches the token entered in Meta's dashboard.
- **Messages are sent but not received**: Check if the recipient number is verified on your Meta Test account (only needed for sandbox test numbers).
- **Infinite message loops**: The webhook checks for incoming status messages and ignores them. It only responds to incoming user messages.
- **Error Logs**: Review server stdout for structured JSON logging with prefix `Meta WhatsApp API Error response`.
